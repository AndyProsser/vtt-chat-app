# Guides

Plain-language guides for the people who run and use VTT Chat App. The architecture documents in
[`../architecture/`](../architecture/OVERVIEW.md) explain **why** things are built the way they are; these
explain **what to do**.

| Guide                               | For                         | Covers                                                                         |
| ----------------------------------- | --------------------------- | ------------------------------------------------------------------------------ |
| [Operator guide](OPERATOR-GUIDE.md) | whoever hosts the server    | Install, first run, configure, operate, back up, update, fix                   |
| [User guide](USER-GUIDE.md)         | players and Dungeon Masters | Join a table, voice, chat, handouts, loot, recording, the DM's tools, settings |

**Status: drafts** (started 2026-11-10). They describe what is built and tested; each guide marks the
steps that have not yet been tried on a real machine by someone other than the author, and those are the
first things to correct. If you follow a guide and it is wrong or unclear, that is a bug in the guide:
tell the author, or fix it and send the change.

Keeping them true: when a feature changes, the guide for it changes in the same commit (see
[CLAUDE.md §17](../../.claude/CLAUDE.md)).
