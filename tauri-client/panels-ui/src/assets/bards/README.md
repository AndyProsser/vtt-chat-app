# Storyteller portraits

Starter artwork for the five storytellers (`shared/src/consts/bards.ts`), flat SVG illustrations that follow light and dark
because they carry their own backgrounds. Each storyteller has a **portrait** (square, used in the app at 34 to 80 pixels)
and a **full** figure (not used yet; for the tale reader). They are stand-ins until richer art arrives: replace a file with
the same name and nothing else changes. The files hold only shapes and colours (no scripts, fonts or links), so they are safe
under the app's strict content security policy.
